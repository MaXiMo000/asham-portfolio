# Security

## Reporting a problem

If you find a security issue with this site, please open a private security advisory
on this repository ("Security" tab → "Report a vulnerability") rather than a public issue.

## Protections

- The site is static: there is no server-side code, database, form handling or user accounts
- No analytics, cookies or tracking scripts
- No third-party JavaScript; fonts are the only external resource
- External links open with `rel="noopener"`
